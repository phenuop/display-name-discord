The `display_name_colors` field takes an array of integers, where each integer is the decimal form of an RGB color (`R × 65536 + G × 256 + B`). Pass a single-element array for a solid color, or multiple values for gradient effects.

---

## Converting Hex to Decimal

Parse the hex color as a 24-bit integer. For example, `#F10000` is `0xF10000`, which equals `15794176`.

```js hex-to-decimal.js
const hexToDecimal = (hex) => parseInt(hex.replace('#', ''), 16);

hexToDecimal('#F10000'); // 15794176
hexToDecimal('#FCFCFC'); // 16579836
hexToDecimal('#000000'); // 0
```

## Gradient Example

Gradient effects (effect ID 2, or the unconfirmed ID 7) use multiple stops in the `colors` array. Up to 5 values have been observed working in community testing.

```json gradient-5-stop.json
{
  "display_name_effect_id": 7,
  "display_name_colors": [0, 4737096, 7105644, 10263708, 16579836]
}
```

<Warning>
  The maximum number of color stops is unconfirmed. Passing more than 5 may silently fail, so verify the applied styles by reading `display_name_styles` in the response.
</Warning>
