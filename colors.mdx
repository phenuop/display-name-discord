The `display_name_colors` field takes an array of whole-number RGB values, where each integer is the decimal form of a color (`R × 65536 + G × 256 + B`). For example, `0xD4A017` is `13934615`. Each array can hold up to 5 colors.

---

## Converting Hex to Decimal

Parse the hex color as a 24-bit integer. Hex strings are rejected, so always convert first.

<CodeGroup>

```ts hex-to-decimal.ts
const hexToDecimal = (hex: string): number => parseInt(hex.replace('#', ''), 16);

hexToDecimal('#F10000'); // 15794176
hexToDecimal('#D4A017'); // 13934615
hexToDecimal('#000000'); // 0
```

```python hex_to_decimal.py
def hex_to_decimal(hex_color: str) -> int:
    return int(hex_color.lstrip("#"), 16)

hex_to_decimal("#F10000")  # 15794176
hex_to_decimal("#D4A017")  # 13934615
hex_to_decimal("#000000")  # 0
```

</CodeGroup>

## Tested Values

Tested on 1 October 2026 against API v10.

| Value | Result | Notes |
| --- | --- | --- |
| `[]` (0 colors) | Saved | Stored as an empty list. Only works in a full request. |
| 1 to 5 colors | Saved | Works on every effect from 1 to 6, even Solid. |
| 6+ colors | Rejected | `400 BASE_TYPE_MAX_LENGTH` "Must be 5 or fewer in length." |
| `0` and `16777215` | Saved | Black and white, the real range. |
| `16777216` | Saved | Above white and not range-checked. Validate it yourself. |
| `-1` | Rejected | HTTP `500 Internal Server Error`. |
| `1.5` | Changed | Stored as `1` (decimals cut off). |
| `"16711680"` (string) | Saved | Converted to the number. |
| `"#ff0000"` | Rejected | `400 NUMBER_TYPE_COERCE`. Convert hex to a number first. |
| `null` inside the array | Rejected | `400 BASE_TYPE_REQUIRED`. |

<Warning>
  Discord does not range-check colors. Make sure every value is between `0` and `16777215` before sending it.
</Warning>

## Gradient Example

Use effect `2` (Gradient) or `6` (Glow) with up to 5 color stops.

```json gradient-5-stop.json
{
  "display_name_font_id": 6,
  "display_name_effect_id": 2,
  "display_name_colors": [13934615, 5812456, 13934615, 5812456, 13934615]
}
```
