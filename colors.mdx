The `display_name_colors` field takes an array of integers where each integer is a decimal representation of an RGB color (i.e., `R × 65536 + G × 256 + B`). For a solid color effect, pass a single-element array. For gradient or multi-stop effects, pass multiple values.

## Converting Hex to Decimal

To convert a hex color like `#F10000` to decimal, parse the hex as a 24-bit integer: `0xF10000 = 15,728,640`. In JavaScript: `parseInt('F10000', 16)` or `0xF10000`.

```js hex-to-decimal.js
// Convert hex string to decimal RGB integer
const hexToDecimal = (hex) => parseInt(hex.replace('#', ''), 16);

hexToDecimal('#F10000'); // 15728640
hexToDecimal('#FCFCFC'); // 16579836
hexToDecimal('#000000'); // 0
```

## Known Color Values

| Decimal   | Hex       |
|-----------|-----------|
| 0         | #000000   |
| 4737096   | #484848   |
| 7105644   | #6C6C6C   |
| 10263708  | #9C9C9C   |
| 16579836  | #FCFCFC   |

## Gradient Example

Gradient effects (effect ID 2, or the unconfirmed ID 7) use multiple stops in the `colors` array — up to 5 values observed in community testing.

```json gradient-5-stop.json
{
  "display_name_effect_id": 7,
  "display_name_colors": [0, 4737096, 7105644, 10263708, 16579836]
}
```

<Note>
  The maximum number of elements in the `colors` array is unconfirmed. Five stops have been observed to work. Passing more may silently fail — always verify the applied styles by reading `display_name_styles` in the response.
</Note>
