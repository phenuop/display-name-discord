Several behaviors of the Display Name Styles API are non-obvious. The feature is reverse-engineered by the community and not documented by Discord, so read this page before deploying to avoid silent failures or styles that appear to apply but are discarded.

---

## HTTP 200 Is Not Confirmation

An HTTP 200 response does not mean the style was applied. Discord may accept the request but ignore the style fields.

<Warning>
  Always read `display_name_styles` from the response and compare it against what you sent.
</Warning>

---

## Per-Guild, Not Global

Display Name Styles are scoped per guild. The endpoint is `/guilds/{guild_id}/members/@me`, so you must send a separate PATCH request for each guild where you want a style. There is no global style setting.

---

## Rate Limits

Like other Discord API endpoints, this endpoint is rate limited. Respect the standard rate limit headers and `429` responses, and avoid sending large bursts of requests when applying styles across many guilds.
