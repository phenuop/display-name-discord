Several behaviors of the Display Name Styles API are non-obvious or counter-intuitive. This feature is **unofficial and reverse-engineered by the community** — it is not documented by Discord and may change without notice. Read this page before deploying; ignoring these gotchas can result in silent failures or styles that appear to apply but are immediately discarded.

<Warning>
  An HTTP 200 response does **not** mean the style was successfully applied. Discord may silently accept the request but ignore the style fields. **Always read `display_name_styles` from the response and compare it against what you sent.**
</Warning>

## Known Gotchas

<AccordionGroup>
  <Accordion title="Per-guild, not global">
    Display Name Styles are scoped per guild. The endpoint is `/guilds/{guild_id}/members/@me` — you must make a separate PATCH request for each guild where you want to apply a style. There is no global style setting.
  </Accordion>

  <Accordion title="Rate limits">
    Like other Discord API endpoints, this endpoint is rate limited. Respect the standard rate limit headers and `429` responses, and avoid sending large bursts of requests when applying styles across many guilds.
  </Accordion>
</AccordionGroup>
