sidebarTitle: "Endpoint"
description: "PATCH /guilds/{guild_id}/members/@me sets or clears bot Display Name Styles. Accepts font, effect, and color fields; returns a display_name_styles object."
---

The `PATCH /guilds/{guild_id}/members/@me` endpoint is the standard Discord guild member update endpoint. Including the three undocumented display name style fields in the request body sets or clears your bot's styled display name for that guild.

```http
PATCH https://discord.com/api/v10/guilds/{guild_id}/members/@me
Authorization: Bot <token>
Content-Type: application/json
```

---

## Request Fields

| Field | Type | Description |
| --- | --- | --- |
| display_name_font_id | ?integer | Font ID to apply. See [Fonts](/fonts). |
| display_name_effect_id | ?integer | Effect ID to apply. See [Effects](/effects). |
| display_name_colors | ?array of integers | 1 to 5 decimal RGB colors. See [Colors](/colors). |

<Warning>
  Always send all three fields together. Sending only one or two is silently dropped. To clear a style, set all three to `null`.
</Warning>

A nickname (`nick`) can be set in the same request.

---

## Response Fields

The response is the guild member object, with an added `display_name_styles` field.

| Field | Type | Description |
| --- | --- | --- |
| display_name_styles | ?object | Present when styles are active, `null` when cleared. |

###### Display Name Styles Structure

| Field | Type | Description |
| --- | --- | --- |
| font_id | integer | The applied font ID. |
| effect_id | integer | The applied effect ID. |
| colors | array of integers | The applied decimal RGB colors. |

<Warning>
  Request and response field names do not match. The request uses `display_name_font_id`, `display_name_effect_id`, and `display_name_colors`. The response uses `display_name_styles.font_id`, `display_name_styles.effect_id`, and `display_name_styles.colors`.
</Warning>

---

## Set Display Name Styles

```json Request
{
  "display_name_font_id": 6,
  "display_name_effect_id": 4,
  "display_name_colors": [15777856]
}
```

```json Response
{
  "user": {
    "id": "123456789012345678",
    "username": "MyBot"
  },
  "nick": null,
  "roles": [],
  "display_name_styles": {
    "font_id": 6,
    "effect_id": 4,
    "colors": [15777856]
  }
}
```

---

## Clear Display Name Styles

Pass `null` for all three fields.

```json Request
{
  "display_name_font_id": null,
  "display_name_effect_id": null,
  "display_name_colors": null
}
```

```json Response
{
  "display_name_styles": null
}
```

---

## Errors

| Error | Cause |
| --- | --- |
| `400 ENUM_TYPE_COERCE` | Font or effect ID out of range (`0`, font `18+`, effect `9+`), or all three fields set to `0` / `[]`. |
| `400 BASE_TYPE_MAX_LENGTH` | More than 5 colors. |
| `400 NUMBER_TYPE_COERCE` | A hex string such as `"#ff0000"` in `display_name_colors`. |
| `400 BASE_TYPE_REQUIRED` | `null` inside the colors array. |
| `500 Internal Server Error` | A negative color such as `-1`. |
| `429` | Rate limited. Wait for `retry_after`. See [Gotchas](/gotchas#rate-limits). |

The `PATCH /users/@me` endpoint accepts the same fields and returns `200`, but saves nothing for bots.
