The `PATCH /guilds/{guild_id}/members/@me` endpoint is the standard Discord guild member update endpoint. Including the three undocumented display name style fields in the request body sets or clears your bot's styled display name for that guild.

```http
PATCH https://discord.com/api/v10/guilds/{guild_id}/members/@me
Authorization: Bot <token>
Content-Type: application/json
```

---

## Request Fields

| Field | Type | Description |
| --- | --- | --- |
| display_name_font_id | ?integer | Font ID to apply. See [Fonts](/fonts). `null` clears it. |
| display_name_effect_id | ?integer | Effect ID to apply. See [Effects](/effects). `null` clears it. |
| display_name_colors | ?array of integers | Decimal RGB colors. Pass one value for a solid color, or up to 5 stops for gradients. See [Colors](/colors). `null` clears it. |

---

## Response Fields

The response is the guild member object, with an added `display_name_styles` field.

| Field | Type | Description |
| --- | --- | --- |
| display_name_styles | ?object | Present when styles are active, `null` when cleared. |

###### Display Name Styles Structure

| Field | Type | Description |
| --- | --- | --- |
| font_id | integer | The applied font ID. |
| effect_id | integer | The applied effect ID. |
| colors | array of integers | The applied decimal RGB colors. |

<Warning>
  Request and response field names do not match. The request uses `display_name_font_id`, `display_name_effect_id`, and `display_name_colors`. The response uses `display_name_styles.font_id`, `display_name_styles.effect_id`, and `display_name_styles.colors`.
</Warning>

---

## Set Display Name Styles

```json Request
{
  "display_name_font_id": 6,
  "display_name_effect_id": 4,
  "display_name_colors": [15777856]
}
```

```json Response
{
  "user": {
    "id": "123456789012345678",
    "username": "MyBot"
  },
  "nick": null,
  "roles": [],
  "display_name_styles": {
    "font_id": 6,
    "effect_id": 4,
    "colors": [15777856]
  }
}
```

---

## Clear Display Name Styles

Pass `null` for all three fields.

```json Request
{
  "display_name_font_id": null,
  "display_name_effect_id": null,
  "display_name_colors": null
}
```

```json Response
{
  "display_name_styles": null
}
```

## Open Questions

The following behaviors are not yet confirmed by community testing:

- The maximum number of elements in the `colors` array.
- Whether effect ID 7 is "Gummy" or "Prism".
- Whether hex color strings are accepted in place of decimal integers.
- The exact rate limit response headers.
