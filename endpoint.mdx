The `PATCH /guilds/{guild_id}/members/@me` endpoint is the standard Discord guild member update endpoint. By including the three undocumented display name style fields in the request body, your bot can set or clear its styled display name for a specific guild.

<Info>
  **Method:** PATCH  
  **URL:** `https://discord.com/api/v10/guilds/{guild_id}/members/@me`  
  **Auth:** `Authorization: Bot <token>`  
  **Content-Type:** `application/json`
</Info>

## Set Display Name Styles

```json Set styles request
{
  "display_name_font_id": 6,
  "display_name_effect_id": 4,
  "display_name_colors": [15777856]
}
```

```json Set styles response
{
  "user": {
    "id": "123456789012345678",
    "username": "MyBot"
  },
  "nick": null,
  "roles": [],
  "display_name_styles": {
    "font_id": 6,
    "effect_id": 4,
    "colors": [15777856]
  }
}
```

## Clear Display Name Styles

```json Clear styles request
{
  "display_name_font_id": null,
  "display_name_effect_id": null,
  "display_name_colors": null
}
```

```json Clear styles response
{
  "display_name_styles": null
}
```

<Warning>
  **Request and response field names DO NOT match.**
  - **Request:** `display_name_font_id`, `display_name_effect_id`, `display_name_colors`
  - **Response:** `display_name_styles.font_id`, `display_name_styles.effect_id`, `display_name_styles.colors`
</Warning>

## Request Fields

<ResponseField name="display_name_font_id" type="integer | null">
  Font ID to apply. See the [Fonts reference](/fonts) for all valid IDs. Set to `null` to clear.
</ResponseField>

<ResponseField name="display_name_effect_id" type="integer | null">
  Effect ID to apply. See the [Effects reference](/effects) for all valid IDs. Set to `null` to clear.
</ResponseField>

<ResponseField name="display_name_colors" type="integer[] | null">
  Array of decimal RGB color integers. For a solid color, pass a single-element array. For gradients, pass up to 5 stops. Set to `null` to clear. See the [Colors reference](/colors) for examples.
</ResponseField>

## Response Fields

<ResponseField name="display_name_styles" type="object | null">
  Present when styles are active; `null` when cleared.
  <Expandable title="properties">
    <ResponseField name="font_id" type="integer">The applied font ID.</ResponseField>
    <ResponseField name="effect_id" type="integer">The applied effect ID.</ResponseField>
    <ResponseField name="colors" type="integer[]">Array of applied decimal RGB color integers.</ResponseField>
  </Expandable>
</ResponseField>

<AccordionGroup>
  <Accordion title="Open questions">
    The following behaviors are unconfirmed by community testing: maximum number of elements in the `colors` array; whether effect ID 7 is "Gummy" or "Prism"; whether font IDs above 12 are valid; whether hex color strings are accepted in place of decimal integers; exact rate limit response headers.
  </Accordion>
</AccordionGroup>
