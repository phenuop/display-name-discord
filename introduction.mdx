Display Name Styles allow a Discord bot to present a styled display name that combines a font (for example Medieval, 8Bit, or Vampyre), a visual effect (for example Neon, Toon, or Glow), and one or more colors. Each style applies to a single guild. Styles are set through undocumented fields on the standard guild member PATCH endpoint.

---

## How It Works

Three fields on the guild member object control the style.

| Field | Type | Description |
| --- | --- | --- |
| display_name_font_id | integer | The typeface rendered for the bot's display name. See [Fonts](/fonts). |
| display_name_effect_id | integer | The visual effect applied on top of the font. See [Effects](/effects). |
| display_name_colors | array of integers | One or more decimal RGB colors used by the effect. See [Colors](/colors). |

```json
{
  "display_name_font_id": 6,
  "display_name_effect_id": 4,
  "display_name_colors": [15777856]
}
```

In this example, font `6` is Modern, effect `4` is Toon, and `15777856` is the decimal form of `#F0C040`.

Colors are plain decimal integers, not hex strings. Convert a hex color to a base-10 integer before sending the request.

Always send all three fields together. A style shows on the bot's profile popout in that guild, but not on the name above its chat messages.
