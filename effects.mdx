The `display_name_effect_id` field accepts an integer that controls how Discord renders the colors applied to your bot's display name. Effects range from a flat Solid fill to styles like Neon and Glow.

---

## Effect IDs

| ID | Effect | Notes |
| --- | --- | --- |
| 1  | Solid        | Flat fill, single color       |
| 2  | Gradient     | Smooth blend between colors   |
| 3  | Neon         | Glowing neon edge             |
| 4  | Toon         | Bold cartoon-style outline    |
| 5  | Pop          | High-contrast pop art style   |
| 6  | Glow         | Soft ambient glow             |
| 7 | Gummy/Prism \* | Unconfirmed |

\* Effect ID 7 has been observed, but whether it is named "Gummy" or "Prism" is unconfirmed. Treat it as experimental.

When using effect ID 2 (Gradient) or effect ID 7, pass multiple color stops in `display_name_colors`. See [Colors](/colors) for gradient examples.
