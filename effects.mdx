The `display_name_effect_id` field accepts an integer that controls how Discord renders the colors applied to your bot's display name. Effects 1 to 6 work for bots. Prism and Gummy exist but are not available to bots.

---

## Effect IDs

Tested on 1 October 2026 against API v10.

| ID | Effect | Client Colors | Result |
| --- | --- | --- | --- |
| 0 |  |  | Rejected (`400 ENUM_TYPE_COERCE`) |
| 1 | Solid | 1 | Saved |
| 2 | Gradient | 1 to 5 | Saved |
| 3 | Neon | 1 | Saved |
| 4 | Toon | 1 | Saved |
| 5 | Pop | 1 | Saved |
| 6 | Glow | 1 to 5 | Saved |
| 7 | Prism |  | Dropped \* |
| 8 | Gummy |  | Dropped \* |
| 9+ |  |  | Rejected (`400 ENUM_TYPE_COERCE`) |

\* Dropped means Discord returns `200` but keeps the previous style. Prism and Gummy are not available to bots.

"Client Colors" is how many colors the Discord client uses for that effect. The API accepts 1 to 5 colors on every effect from 1 to 6, even Solid.

For multi-color styles, use effect `2` (Gradient) or `6` (Glow). See [Colors](/colors) for gradient examples.
