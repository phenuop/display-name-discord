The `display_name_font_id` field accepts an integer ID that controls which typeface Discord renders for your bot's display name in a guild. The IDs below come from Discord's own font list.

---

## Font IDs

| ID | Font |
| --- | --- |
| 3 | Sakura |
| 4 | Jellybean |
| 6 | Modern |
| 7 | Medieval |
| 8 | 8Bit |
| 10 | Vampyre |
| 11 | gg sans |
| 12 | Tempo |
| 13 | Monkey Bars |
| 14 | Mainframe |
| 15 | Headbang |
| 16 | Journal |

<Warning>
  Font IDs are not sequential. IDs 1, 2, 5, and 9 do not appear in Discord's list. An unrecognized ID may cause the style to silently not apply, so verify by reading `display_name_styles` from the response.
</Warning>
